⛭ MCP TOOLS

OFF
ENABLE MCP TOOLS (let the cognition core call tools mid-reply)

MCP (Model Context Protocol) servers expose tools the model can invoke while it answers — it may think, call a tool such as browser_snapshot, read the result, then continue. Tool calls run inside the chat and are folded away by default so they never interrupt spoken output. With this switch off, no tools are sent and the terminal behaves as a plain chat.

◈ MCP SERVERS

Exactly like LM Studio: paste a stored mcpServers document and press SAVE SERVERS. Each server is then spawned on demand with its START button below.

◈ INSTALLED SERVERS

Press START to connect a server (e.g. Playwright); the indicator turns green and its tools appear. Toggle any individual tool to control whether the model may call it. Use the sidebar menu on the TERMINAL tab to enable or disable a whole server for the current session only.
